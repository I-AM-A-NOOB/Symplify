# Symplify — Agent instructions

Read `.Agent/DEVELOPER_GUIDE.md` before changing this repository: it explains the source
layout, architecture invariants, known RinUI/Qt traps, how to build and how versions work.

**Mandatory maintenance rule:** after any major change (new/moved modules or components,
architecture or data-flow changes, build or versioning changes), update
`.Agent/DEVELOPER_GUIDE.md` in the same commit. Outdated docs must not be left behind.
